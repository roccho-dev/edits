# merge quality definition

This package treats mergeable quality as evidence that the scoped change contributes from local behavior up to the highest asset-transfer purpose.

For #39-#48, that means:

1. current candidate behavior is preserved;
2. post-merge CI cannot be skipped silently;
3. core/ports cannot import concrete adapters;
4. old implementation paths cannot reappear as executable paths;
5. all source adapters satisfy the same provider contract;
6. hq source rows are proven as real completion input;
7. malformed rows cannot become valid candidates;
8. candidate, LSP, and UX outputs are canonical snapshots;
9. large fixtures stay within a documented budget;
10. #37 cannot close until final post-merge evidence is posted.
