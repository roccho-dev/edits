# boundary

Adopt provider-port boundary and delay external server work.

Keep in-process Vimscript as the default provider adapter. Vim keeps ownership of selected index, ghost, commit and undo safety. Candidate core remains merge, rank and decorate only.

Add versioned request and response records, provider adapter validation, in-process adapter boundary and editor orchestrator boundary.

This keeps current proof value while making later editor support a thin adapter instead of a rewrite.
