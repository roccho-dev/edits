# merge gate

Do not merge as implementation until these are true:

1. Overlay artifact is applied to `packages/auto-complete`.
2. Generated bytecode is absent.
3. `./test/run.sh` passes.
4. Immutable archive hash is preserved in manifest.
5. ADR raw event is merged in `roccho-dev/adrs`.
6. Scope still excludes LSP transport for this step.

This PR is acceptable as proposal evidence before those implementation-gate checks are complete.
