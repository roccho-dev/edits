# rejected alternatives

| alternative | reason |
|---|---|
| immediate full external protocol extraction | adds protocol and service cost while editor-owned UX remains in the editor |
| permanent Vimscript monolith | makes a second editor require a rewrite |
| protocol item as core item type | ties domain and ranking semantics to one client protocol |

Chosen path: small provider contract now, adapter extraction later only when a second client needs it.
